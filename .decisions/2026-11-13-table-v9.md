# Decision

## Title

Use explicit TanStack Table v9 filtering and sorting features

## Date

2026-11-13

## Status

Accepted

## Decision

Use useTable with a stable tableFeatures registry containing column filtering,
row sorting, and their row models. Pass built-in filter/sort functions directly.
The toolbar remains the owner of filter and sort state.

## Context

PR #179 upgrades to v9, which removes useReactTable and the v8 row-model options.
The old compiler exclusion also hid synchronous effect-driven state resets.

## Alternatives

Keep v8 or use the deprecated legacy adapter with all features bundled.

## Reason

The explicit v9 API preserves behavior and avoids bundling unused features.
Guarded render-time resets keep route tags and search selection synchronized
without cascading effect updates or disabling lint checks.

## Consequences

Component tests exercise date/kana sorting, combined filters, clearing filters,
and route changes against the installed table implementation.

## Revisit Conditions

The list gains additional table features or changes state ownership.
