# Archived repository content

Articles, works, About, and generated thumbnails lived here until the D1/R2
cutover on 2026-08-13. They are kept as a readable copy of what the repository
shipped at that point; the live content is in D1 and R2, and nothing here is
read by the build, the tests, or any workflow.

Editing a file in this directory changes nothing. Edit the content through the
editor, which writes to D1/R2 through the author API.

See `.decisions/database-only-content-source.md`.
